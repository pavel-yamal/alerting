Оповещение

Приказ считается подлинным, только если его подписали уполномоченные лица — это проверяется по ключу организации, полученному при регистрации, а не по слову сервера.

Ранее

Это демонстрационный веб-клиент: проверка подписи выполняется в клиенте исполнителя на стенде, а не в самом телефоне. Пока страница закрыта или телефон спит, приказ сюда не придёт — для этого нужно приложение с push-уведомлениями.
