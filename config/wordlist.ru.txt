#
# Rules this list follows, and any replacement must keep:
#   * Concrete, neutral nouns. A code word must never sound like an instruction.
#   * No ё: it is collapsed to е so a written and a spoken code cannot diverge.
#   * Distinct, 2-14 Cyrillic letters, uppercase.
#   * Exactly 1024 entries, because each word carries 10 bits.
#
# Changing this file changes every wake code. Reissue the printed codebook cards
# with it (docs/07-drills-and-training.md).
